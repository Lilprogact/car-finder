Settings

GitHub token

A fine-grained token for car-finder-engine only, with Actions: read and write, Contents: read-only, 90-day expiry. It stays on this device, encrypted with your password.

How to make a new token
  1. GitHub → your profile photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: Car Finder. Expiration: 90 days. Resource owner: you.
  3. Repository access: Only select repositories → car-finder-engine.
  4. Repository permissions: Actions → Read and write. Contents → Read-only. (Metadata is added automatically.)
  5. Generate, copy it, paste it above and tap Save token.
